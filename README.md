# ECHO

Личный ИИ-агент в духе Джарвиса: с ним можно говорить, он отвечает **твоим голосом**, а по роли — дворецкий, второй мозг и операционка жизни.

Репозиторий только что заведён. Первый коммит — не код, а карта поля: кто уже сделал похожее, как у них это собрано, что из твоих репозиториев можно взять сразу.

## Документы

- [Исследование ландшафта](docs/research.md) — кластеры рынка, архитектуры, топ по функциям и по качеству реализации, разбор твоих репозиториев, что переиспользовать.

## Тезис

Не ещё один чат с озвучкой. Два жёстких условия:

1. Голос на выходе — **твой**, не чужой персонаж и не «дефолтный ассистент».
2. Агент **делает**, а не только отвечает: память, инструменты, каналы, проактивность.
